# Security policy

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Zaheer-verse/deliberate-dev-claude/security/advisories/new) for suspected command execution, path escape, or private-data exposure. Include the affected version, operating system, Python and Git versions, minimal reproduction, impact, and mitigation ideas. Redact credentials and private project data.

If private reporting is unavailable, open a public issue asking the maintainer to enable a private reporting channel. Do not disclose vulnerability details in that issue.

Security fixes target the latest release. The plugin contains agent instructions and local helpers; workflow records are evidence, not proof that an agent actually executed the recorded commands.
